# メール作成ガイドライン

## 基本方針

SALES_STRATEGY.mdの「メッセージング」セクションを基に、各営業先の `overview`（事業概要）と `match_reason`（マッチ理由・課題）に合わせてカスタマイズする。

## 件名

- 短く具体的に（20文字以内が理想）
- 相手のメリットが伝わるように
- 「ご提案」「お知らせ」等の汎用的な件名は避ける
- **営業先ごとに変える。** 全件同じ件名にしない。相手の業種・特徴・課題に触れる
- **SALES_STRATEGY.md に件名パターンやA/Bテスト指示がある場合、必ずそれに従う。** 複数パターンが定義されていればバリエーションを使い分ける
- 例: 「貴校の就職支援プログラムに関して」「IT人材育成×AI面接トレーニングのご相談」

## 本文構成

1. **冒頭の挨拶**（1-2行）: 相手の組織名に触れ、なぜ連絡したか簡潔に
2. **課題提起**（2-3行）: 相手が抱えているであろう課題を具体的に
3. **解決策**（2-3行）: 自社サービスがどう解決するか
4. **実績/証拠**（1-2行）: 数字や事例があれば
5. **CTA**（1行）: 次のアクション（ミーティング、デモ、返信等）
6. **署名**: SALES_STRATEGY.mdの「送信者情報」セクションを使用

## カスタマイズの具体的なやり方

**最も重要なポイント:** 冒頭1-2行で「なぜ御社に連絡したか」を、その営業先固有の情報で書く。汎用的な文面にしない。

カスタマイズの情報源:
- `overview`: その営業先の事業概要。具体的な取り組み・サービス・特徴が書かれている
- `match_reason`: なぜターゲットとして選んだか。相手の課題・ニーズが書かれている

**冒頭だけでなく本文全体を個別化する。** overview から読み取れる相手の具体的な数値・実績・取り組みに言及し、テンプレートの差し替えではなく相手に合わせた文脈で課題提起→解決策を組み立てる。

**悪い例（冒頭だけ差し替えでテンプレ感が強い）:**
> 貴校のIT・ゲーム系人材育成への取り組みを拝見し、ご連絡いたしました。
> 昨今、○○業界では△△が課題となっており...（以下全員同じ）

**良い例（全体が相手に合わせて書かれている）:**
> 貴校の約700社参加の合同企業説明会や模擬面接など、充実した就職支援体制を拝見しご連絡いたしました。
> これだけの規模の就活支援を行われている中で、学生一人ひとりの面接練習機会の確保は課題ではないでしょうか。

overview や match_reason から、その営業先だけに当てはまる具体的な文言を複数箇所に散りばめる。

## 署名・CTA

- SALES_STRATEGY.mdの「送信者情報」セクションから署名ブロックを取得し、本文末尾に付与する
- 日程調整リンク（Timerex等）がある場合はCTAとして本文に含める（例: 「よろしければ以下よりご都合の良い日時をお選びください」）

## 送信方法

`send_and_log.py` で送信+DB記録を一括実行する（SKILL.mdの手順を参照）。

## 注意事項

- 全体で200-300文字以内に収める（署名除く）
- 1メール1CTA（複数のお願いをしない）
- 添付ファイルは送らない（初回）
- 敬語は丁寧すぎず、ビジネスライクに
