# メール作成ガイドライン

## 基本方針

SALES_STRATEGY.mdの「メッセージング」セクションを基に、各営業先の `match_reason` に合わせてカスタマイズする。

## 件名

- 短く具体的に（20文字以内が理想）
- 相手のメリットが伝わるように
- 「ご提案」「お知らせ」等の汎用的な件名は避ける
- 相手の業種や課題に触れるとクリック率が上がる

## 本文構成

1. **冒頭の挨拶**（1-2行）: 相手の組織名に触れ、なぜ連絡したか簡潔に
2. **課題提起**（2-3行）: 相手が抱えているであろう課題を具体的に
3. **解決策**（2-3行）: 自社サービスがどう解決するか
4. **実績/証拠**（1-2行）: 数字や事例があれば
5. **CTA**（1行）: 次のアクション（ミーティング、デモ、返信等）
6. **署名**: BUSINESS.mdの組織情報を使用

## 注意事項

- 全体で200-300文字以内に収める
- 1メール1CTA（複数のお願いをしない）
- 添付ファイルは送らない（初回）
- 敬語は丁寧すぎず、ビジネスライクに
