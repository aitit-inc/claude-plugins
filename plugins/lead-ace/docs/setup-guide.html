Lead Ace セットアップガイド

自律型リード獲得プラグインの環境構築手順

前提条件: macOS を使用していること。Anthropic の有料プラン（Pro / Max / Team）に加入していること。

目次

  1. ツール一括インストール（スクリプト実行）
  2. Cursor のインストール
  3. Claude Code 拡張機能のセットアップ
  4. Google Cloud Console の設定（gog 用）
  5. gog CLI の認証設定
  6. Gmail Connector の接続
  7. Claude in Chrome のインストール
  8. Lead Ace プラグインのインストール
  9. 動作確認
1

ツール一括インストール

スクリプト

ターミナルを開いて、以下のコマンドを実行してください。
Homebrew・Git・Python3・SQLite3・gog CLI・Claude Code CLI がまとめてインストールされます。

ターミナルの開き方: Spotlight（⌘ + Space）で「ターミナル」または「terminal」と入力して Enter
curl -fsSL https://raw.githubusercontent.com/aitit-inc/claude-plugins/main/plugins/lead-ace/docs/setup-env.sh | bash
各ツールはインストール前に既存チェックを行います。既にインストール済みのものはスキップされるため、何度実行しても安全です。
Homebrew のインストール時にパスワード入力を求められることがあります。Mac のログインパスワードを入力してください。
2

Cursor のインストール

手動
  1. Cursor 公式サイト にアクセス
  2. 「Download」ボタンをクリックして .dmg ファイルをダウンロード
  3. ダウンロードした .dmg を開き、Cursor を Applications フォルダにドラッグ
  4. Cursor を起動して初期セットアップを完了
既にインストール済みの場合はスキップしてください。
3

Claude Code 拡張機能のセットアップ

手動
  1. Cursor を開く
  2. サイドバーの拡張機能アイコン（四角が4つ並んだアイコン）をクリック
  3. 検索欄で Claude Code と検索
  4. 「Claude Code」（発行元: Anthropic）をインストール
  5. インストール後、サイドバーに Claude Code のアイコンが表示される
  6. Claude Code パネルを開き、Anthropic アカウントでログイン
拡張機能に CLI がバンドルされているため、Cursor のターミナルからも claude コマンドが使えます。
Step 1 で claude-code CLI も別途インストール済みなので、Cursor 外のターミナルでも利用可能です。
4

Google Cloud Console の設定

手動

gog CLI でメール送信を自動化するために、Google Cloud の OAuth 認証情報が必要です。

gog のセットアップをスキップする場合: Step 4〜5 を飛ばしても、Step 6 の Gmail Connector を設定すればメールの検索・閲覧・ドラフト作成までは可能です。ただし、メールの自動送信はできないため、下書きを手動で送信する運用になります。

4-1. プロジェクト作成

  1. Google Cloud Console - プロジェクト作成 にアクセス
  2. プロジェクト名を入力（例: lead-ace）して「作成」

4-2. Gmail API を有効化

  1. Gmail API のページ にアクセス
  2. 上部の「有効にする」ボタンをクリック

4-3. OAuth 同意画面の設定

  1. OAuth 同意画面 にアクセス
  2. User Type は「内部」を選択（自分のみが利用するため、テストユーザー追加や Google 審査が不要で簡単です）
  3. アプリ名（例: Lead Ace）、サポートメールを入力して保存

4-4. OAuth クライアント ID の作成

  1. 認証情報 - クライアント作成 にアクセス
  2. アプリケーションの種類: 「デスクトップ アプリ」 を選択
  3. 名前を入力して「作成」
  4. 作成後、「JSON をダウンロード」をクリックして保存
    （client_secret_XXXX....json というファイルがダウンロードされます）
ダウンロードした JSON ファイルは次のステップで使います。場所を覚えておいてください。
5

gog CLI の認証設定

手動（ターミナル）

ターミナルで以下のコマンドを順番に実行してください。

5-1. 認証情報ファイルを登録

ダウンロードした JSON ファイルのパスを指定します（通常は Downloads フォルダにあります）:

gog auth credentials ~/Downloads/client_secret_*.json

5-2. Gmail アカウントを認証

自分のメールアドレスに置き換えて実行してください:

gog auth add your-email@gmail.com

ブラウザが開くので、Google アカウントでログインして許可してください。

5-3. 動作確認

export GOG_ACCOUNT=your-email@gmail.com gog gmail labels list

Gmail のラベル一覧が表示されれば成功です。

6

Gmail Connector の接続

手動

Claude から直接 Gmail を検索・閲覧するための公式 Connector を設定します。

  1. claude.ai にアクセスしてログイン
  2. 新しいチャットを開く
  3. 入力欄の左にある 「+」ボタン をクリック
  4. 「Connectors」 の横の「+」をクリック
  5. 「Gmail」 を選択
  6. 「Connect」をクリックして Google アカウントで認証
この Connector は claude.ai と Claude Desktop アプリで共有されます。
Claude Code（Cursor 内）からも自動的に利用可能になります。
7

Claude in Chrome のインストール

手動

Web フォームの自動入力や SNS DM 送信に使用するブラウザ拡張機能です。

  1. Chrome Web Store - Claude にアクセス
  2. 「Chrome に追加」をクリック
  3. 拡張機能のポップアップで Claude アカウントにログイン
  4. Claude Code（Cursor のターミナル）で接続を確認:
    /chrome
Chrome または Edge のみ対応です。Brave・Arc 等では動作しません。
有料プラン（Pro / Max / Team / Enterprise）が必要です。
8

Lead Ace プラグインのインストール

手動（Claude Code 内）

Cursor を開き、Claude Code パネルのチャット欄に以下を入力して実行します。

8-1. マーケットプレイスを追加

/plugin marketplace add aitit-inc/claude-plugins

8-2. プラグインをインストール

/plugin install lead-ace@surpassone-plugins

8-3. プラグインを反映

/reload-plugins

8-4. インストール確認

チャット欄に /plugin と入力すると管理画面が開きます。「Installed」タブに lead-ace が表示されていれば成功です。

9

動作確認

手動

セットアップが正しく完了したか確認しましょう。

9-1. プロジェクトを初期化

Claude Code で営業プロジェクトを作成します:

/setup test-project

ディレクトリと DB が作成されれば OK です。

9-2. 各ツールの接続確認チェックリスト

  • Claude Code — Claude Code パネルが応答する
  • gog CLI — ターミナルで gog gmail labels list が動作する
  • Gmail Connector — Claude に「最新のメールを確認して」と依頼して応答がある
  • Claude in Chrome — Claude Code で /chrome を実行して「Connected」と表示される
  • Git — ターミナルで git --version が表示される
