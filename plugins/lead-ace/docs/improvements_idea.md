# スキル改善アイディア

## 1. ✅ 連絡先取得の深掘り不足（最重要）

現状の enrich-contacts.md は「トップ→お問い合わせ→会社概要→アクセス」の4ページしか見ない。
大企業ほど問い合わせ導線が複雑で、この4ページでは見つからないことが多い。

手作業だと見つかるのは、サイト内を回遊して辿り着くから。例えば:
- 「法人のお客様」→「パートナー募集」→ フォーム
- 「採用情報」ページのフッターに代表メール
- 「ニュースリリース」に広報メール
- 「IR情報」→「お問い合わせ」に別窓口
- サイトマップから隠れたコンタクトページ発見
- 「プライバシーポリシー」末尾に管理者メール

**改善案:** enrich-contacts.md の探索手順を「4ページ固定」→「サイト構造を把握してから探す」に変える。
具体的には: まずトップページのナビゲーション・フッターのリンク一覧を取得し、コンタクト情報がありそうなページを複数候補挙げて順に当たる。

**トレードオフ:** 1件あたりの探索時間が増える。現状5件バッチで並列だが、1件あたり探索ページ数を増やすなら3件バッチにするか、探索の深さに上限（最大8ページ等）を設ける。

## 2. ✅ 「連絡先なし」のまま登録される問題

現状: email/form両方nullでもDBに登録 → outbound時にスキップ → リスト残数を見かけ上膨らませるだけ。
EVALUATION_REPORTでも「channel=noneで16件失敗」が最大の問題として指摘されている。

**改善案:** build-listのPhase 2完了後、連絡先なしの候補に対して「再探索」ステップを追加する。
WebSearchで「{会社名} メールアドレス」「{会社名} 問い合わせ」等を検索し、公式サイト以外（業界ディレクトリ、プレスリリース配信サイト等）からも拾う。

## 3. ✅ outboundスキルが戦略の指示を守らない

SALES_STRATEGY.mdに書いてあるのに実行されていないこと:
- 件名A/Bテスト（4パターン用意済みなのに毎回同じ件名）
- 送信タイミング（火〜木AM10-11指定なのに無視）
- 本文の個別化（冒頭1行だけ差し替えでテンプレ感が強い）

これはoutboundスキルの指示が弱いか、サブエージェントがSALES_STRATEGY.mdの該当セクションを十分に参照していない可能性。
outbound SKILLに「件名は必ずSALES_STRATEGY.mdのパターンからランダム選択」「冒頭は相手の具体的な数値・実績に言及」等を明示的に書くべき。
