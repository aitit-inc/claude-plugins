# surpassone-plugins

SurpassOne Inc. が提供する Claude Code プラグインのマーケットプレイスです。

## セットアップ

Claude Code 内で以下を実行:

```
/plugin marketplace add aitit-inc/claude-plugins
```

## プラグイン一覧

| プラグイン | 概要 |
|---|---|
| [sales-agent](./plugins/sales-agent/) | セールス活動の全工程を自動化（戦略策定・リスト作成・アウトバウンド・結果収集・PDCA改善） |

インストール例:

```
/plugin install sales-agent@surpassone-plugins
```

## 更新

```
/plugin marketplace update
/plugin update <plugin-name>@surpassone-plugins
```
