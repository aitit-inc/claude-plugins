# surpassone-plugins

SurpassOne Inc. が提供する Claude Code プラグインのマーケットプレイスです。現在公開中のプラグインはありません。

## セットアップ

Claude Code 内で以下を実行:

```
/plugin marketplace add aitit-inc/claude-plugins
```

## 更新

```
/plugin marketplace update
/plugin update <plugin-name>@surpassone-plugins
```
